## Testing

Install the project dependencies:

```bash
python3 -m pip install -r requirements.txt
```

Run the backend FastAPI tests:

```bash
python3 -m pytest tests -q
```

The test suite exercises the app routes in a separate tests directory and verifies the API behavior with real HTTP requests.
